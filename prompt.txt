Block 1 — Fibonacci Priority State Register (Sequential)

Triggered on posedge clk, there should be asnychronous reset rst_n on negedge
On reset: initialize internal 4-bit Fibonacci register fib_pri_reg to 4'b0001
On every clock: advance fib_pri_reg using a left-shift LFSR-style step
This produces a pseudo-random rotating priority sequence seeded externally
dynamic_highest_priority is a 2-bit wire tapping fib_pri_reg[1:0]

Block 2 — Dynamic Priority Arbitration (Combinatorial)
Triggered on always @(*)
Default all outputs to 0 at top of block — no latches permitted
Use dynamic_highest_priority as case selector over 4 priority orderings
Within each case use cascaded if/else if to grant exactly one master
Assert master_gnt[N] = 1'b1 for the highest-priority requesting master
If no master requests, master_gnt stays 4'b0000
Only one master_gnt bit may be high at any time — mutual exclusion is mandatory

Block 3 — Memory Bank Routing (Combinatorial, inside same always block)
After arbitration, route the granted master to the correct memory bank based on address LSB:
for even addresses:
If master_gnt[0] and master_addr_0[0] is 0 drive bank0_req, bank0_cmd, bank0_addr
If master_gnt[1] and master_addr_1[0] is 0 drive bank0_req, bank0_cmd, bank0_addr
For odd addresses:
If master_gnt[2] and master_addr_2[0] is 1 drive bank1_req, bank1_cmd, bank1_addr
If master_gnt[3] and master_addr_3[0] is 1 drive bank1_req, bank1_cmd, bank1_addr
Both these can be active simultaneously for different masters.

Follow these Coding Rules:
Active-low reset rst_n
All combinatorial outputs must have defaults at top of always block
No hardcoded master count — structure must be readable and extensible

In case 2'b00, master_gnt[0] must be asserted as 1'b1 when master_req[0] is high — do NOT mask it to 1'b0.
